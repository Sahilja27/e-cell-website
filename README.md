# E-Cell Website

A modern and responsive website developed for the **Entrepreneurship Cell (E-Cell)** to provide students with information about entrepreneurship activities, events, initiatives, and the E-Cell community.

The project focuses on creating a clean, engaging, and user-friendly web experience with a modern interface and responsive design.

## 🚀 Features

* 📱 Responsive design for desktop, tablet, and mobile
* 🎨 Modern and interactive user interface
* 🏢 E-Cell information and initiatives
* 📅 Events and activities
* 👥 Team/member information
* 📢 Announcements and updates
* ⚡ Fast and optimized frontend
* 🤖 AI-powered functionality using Google Gemini API

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Sahilja27/e-cell-website.git
```

### 2. Navigate to the project

```bash
cd e-cell-website
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env.local` file in the root directory:

```env
GEMINI_API_KEY=your_api_key_here
```

> **Important:** Never commit API keys or other sensitive credentials to GitHub.

### 5. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL displayed in the terminal.
